# Intelligent Study & Productivity Analytics System

## Overview
This project analyzes study behavior using data science and machine learning techniques. It tracks study patterns, computes productivity metrics, and predicts task completion using regression models.

## Features
- Study hours analysis
- Productivity score calculation
- Consistency measurement
- Data visualization (graphs)
- Machine Learning prediction (Linear Regression)
- Model saving and loading

## Tech Stack
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning
A regression model is used to predict task completion based on study hours.

## Future Scope
- Time-series forecasting
- Personalized recommendations
